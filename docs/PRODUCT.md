## 1. 一句话定位

山谷之声是一位安静的心理陪伴伙伴：帮你被听见，也帮你看清自己。  
聊天是主线；自我觉察与投射类小游戏是入口和节奏调节器——不是娱乐大厅，更不是诊疗室。

## 3. 我们要解决什么

| 用户当下的状态 | 常见诉求 | 山谷之声提供什么 |
| --- | --- | --- |
| 心里乱、说不清 | 「有人听我说说」 | 低压力陪伴对话 |
| 想弄明白自己 | 「我到底怎么了 / 我在想什么」 | 轻量觉察与投射游戏（非诊断） |
| 不想正经聊 | 「先玩一下 / 摆一摆」 | 答案之书、OH 卡、迷你沙盘等 |
| 深夜、脆弱 | 「别丢下我」 | 在场感 + 危机时转介现实帮助 |

## 4. 目标用户（初稿）

**主用户**：18–30 岁、压力偏高、偶尔想找人说话、也愿意做一点自我探索的年轻人（学生 / 职场新人）。

**次用户**：有陪伴需求、但对「心理咨询」有距离感、更愿意从卡片 / 小游戏进入的人。

**明确不做**：替代心理咨询、精神医学诊断、危机干预专业服务。

## 5. 产品原则

1. **先陪伴，后工具**：用户只想倾诉时，不推测评、不推游戏。
2. **觉察不是诊断**：不贴病名，不说「你是抑郁/焦虑症」。
3. **游戏是镜子，不是答案**：投射结果与画像是「今天可以想想的提示」，不是命运裁定。
4. **少而稳**：一次只做一个轻动作；界面安静，不刷分、不连抽、不打卡羞辱。
5. **安全优先**：危机信号出现时，停止游戏玩法，给出热线与现实求助指引。
6. **游客能完整体验主线，绑定打开沙盘推演**：陪我聊聊、答案之书、OH 卡对游客开放；**沙盘推演**在绑定后开放（留下可回看的山谷，并做一轮轻推演）。

### 6.3 主导航与玩法落位（已定）

一级只有三个模块，不做成游戏大厅：

```
山谷之声
├── 陪我聊聊          ← 主线陪伴对话（可含情绪色卡等轻入口）
├── 答案之书          ← 独立秒开仪式
└── 自我探索
    ├── OH 卡         ← 首发（游客可用）
    ├── 山谷日记      ← 首发（游客可写；回看需绑定）
    ├── 沙盘推演      ← 绑定后开放
    └── （后续）人格疗愈游、拆信等
```

| 模块 | 角色 | 首发内容 | MVP 做法 |
| --- | --- | --- | --- |
| **陪我聊聊** | 主线 | 陪伴对话 | 现有对话能力；可接收日记/OH/沙盘上下文 |
| **答案之书** | 秒开仪式 | 答案之书完整可玩 | 翻页短句 + 一句陪伴式回应；可「去聊聊」 |
| **自我探索** | 投射 / 觉察 | **OH 卡 + 山谷日记** | OH：抽卡联想；日记：写→投射点评→支持；均可「去聊聊」 |
| 自我探索 · 绑定后 | 深度外化 + 轻推演 | **沙盘推演**；日记/OH 档案回看 | 见 8.1、8.3 |

**上线节奏**

| 波次 | 交付 | 目的 |
| --- | --- | --- |
| 波次 1 | 三模块壳 + **陪我聊聊** + **答案之书** | 立住导航；验证「仪式 → 聊」 |
| 波次 2 | **自我探索 · OH 卡 + 山谷日记** | 投射与书写双入口 |
| 波次 3 | 绑定体系 + **沙盘推演** + 日记/沙盘回看 | 注册理由：留下山谷并看见变化 |

默认心智：想说话 → 陪我聊聊；想轻触一下 → 答案之书；想看看自己 → 自我探索（抽卡或写日记）；想摆盘推演 / 回看轨迹 → 绑定。

## 7. 人格测评：专业框架 × 疗愈小游戏

### 7.1 原则

- **底层**：大五人格（OCEAN）为主；可借鉴 HEXACO 的「诚实-谦逊」做加分项，但不宣称正式量表分数。
- **表层**：情景选择、拖拽、配色、小路分叉等，**禁止 Likert 长问卷**。
- **结果**：疗愈向「山谷气质画像」（如「雾气里的倾听者」），附 5 维雷达的**柔软隐喻**，不给临床标签。
- **动态感**：走路/光影/天气随选择变化；结束有一段短动画，而非 PDF 式报告墙。

### 7.2 玩法示意（待共创细化）

| 维度 | 问卷味（不要） | 游戏味（要） |
| --- | --- | --- |
| 外向性 | 「我是个外向的人」1–5 | 山谷路口：走向篝火人群 / 独自溪边 |
| 宜人性 | 「我总是体贴他人」 | 两只小动物打架：你选劝和 / 走开 / 护一方 |
| 尽责性 | 「我做事有条理」 | 整理溪边石子：仔细码齐 / 随便堆 / 先去玩 |
| 情绪稳定 | 「我很少焦虑」 | 突降暴雨：撑伞慢慢走 / 奔跑找屋 / 站着淋一会 |
| 开放性 | 「我喜欢新观念」 | 山洞壁画：走近细看 / 拍张照离开 / 自己补一笔 |

完成约 8–10 个情景节点 → 生成画像 → 可选「带进对话」或「仅本次看看」。  
绑定用户可存档与对比「上个月的我」；未绑定仅当次有效。

## 8. 账号与数据

```
打开小程序
  ├─ 游客模式（默认）
  │    · 可用：陪我聊聊、答案之书、自我探索·OH 卡
  │    · 数据仅本地 / 当次；关小程序或清缓存即无
  │    · 看到沙盘推演入口时，温和说明「绑定后可摆盘并留下推演」
  └─ 微信一键登录绑定
       · 云端持久化：对话摘要、OH 卡回顾、今日心情、沙盘成品与推演记录等
       · 开放：**沙盘推演**
       · 可跨设备续上「山谷里的自己」
```

**原则补充**

- 绑定话术偏「留下这盘山谷，并慢慢推演」，避免「登录才能玩」的逼迫感。
- 游客点沙盘：可看预览/示例盘，完整摆放、保存与推演需绑定。
- 游客若中途绑定：询问是否把**本次会话**合并进账号（默认建议合并当次）。
- 危机相关原文：即使绑定，也最小化存储（可存「触发过安全回复」标记，不存详细自伤描述——技术细则后补）。

### 8.1 绑定权益：沙盘推演（已定）

**一句话**：绑定后，用户可在山谷里摆一盘，并请山谷之声陪着做一轮轻推演——不是算命，不是象征词典判读。

**流程**

```
进入沙盘推演（需绑定）
  → 在山谷场景拖拽 12–20 个意象，摆成「今日一盘」
  → 保存成品（云端，可回看）
  → 点选 1 个焦点物件（或「整盘感觉」）
  → 推演（3 步内结束）：
       1. 反映：你看到的远近/遮挡/孤立等（只描述布局，不下诊断）
       2. 邀请：若它会动一步，你希望它往哪？
       3. 收束：一句陪伴 + 「去聊聊」把这盘带进陪我聊聊
```

**推演边界（硬规则）**

- 禁止自动弹出「房子=家庭、蛇=性」等象征词典。  
- 禁止预言未来、替用户做决定。  
- 用户不说话时，只做布局反映 + 一个轻问；不连问。  
- 危机信号出现 → 中断推演，走安全回复。

**与「只摆不推」的区别**

| | 仅迷你沙盘 | 沙盘推演（本产品绑定权益） |
| --- | --- | --- |
| 摆放保存 | 有 | 有 |
| 山谷之声介入 | 可选一句邀请 | **固定轻推演 3 步** |
| 产品记忆 | 今日沙盘图 | 沙盘图 + 焦点物件 + 推演摘要（绑定云端） |

**暂缓**：循序渐进「山谷小路」项目——以后若要做，再单开；不占用绑定权益名额。

#### 绑定引导文案方向

- 好：「绑定后，可以摆一盘山谷，并留下这次推演。」  
- 不好：「登录解锁全部游戏。」

### 8.2 可跟随成长、能看见变化的能力（共创清单）

绑定解决的是「记得你」；下面这些解决的是「过一段时间，你看得出自己变了」。  
原则：**看见变化，不考核变化**——不做连续打卡羞辱、不做成长分数排行。

| 能力 | 怎么跟随 | 用户怎么「看见变化」 | 和现有模块关系 | 匹配度 | 建议时机 |
| --- | --- | --- | --- | --- | --- |
| **沙盘时间轴** | 每次推演存一盘；可按周/月回看 | 并排两盘：「月初的桥在边上，现在到中间了」——布局变化即成长隐喻 | 绑定权益自然延伸 | ★★★★★ | 沙盘推演上线后立刻做「历史回看」 |
| **情绪天气年轮** | 色卡/今日心情按日落点；像年轮或山谷天空相册 | 月视图上看「阴雨变少了」或「颜色从灰到暖」 | 挂陪我聊聊轻入口 | ★★★★★ | 色卡一做就可存；成本低、疗愈感强 |
| **山谷日记 + 投射点评** | 写一段 → 投射式反映 → 支持收束；绑定可存档回看 | 月视图/关键词溪流；对比「那时写的 / 现在的语气」 | 自我探索或陪我聊聊侧门 | ★★★★★ | 见 8.3；强跟随、强成长感 |
| **给未来的信 → 拆信** | 写给 7/30 天后的自己；到期推送拆开 | 并排「当时的我 / 现在的我」两段话 | 自我探索或聊聊内 | ★★★★☆ | 中期；可与日记共用写作框 |
| **OH 卡主题溪流** | 记录常抽到的意象主题（路、水、门、人影…）非单卡迷信 | 「这月你常停在『门』，上月常停在『雨』」 | OH 卡绑定后增强 | ★★★★☆ | OH 卡稳定后 |
| **山谷气质复测** | 人格疗愈游每季可再走一遍 | 两次雷达/气质名温和对比：「开放性那条小路更亮了」 | 自我探索后续 | ★★★★☆ | 人格游戏上线后 |
| **对话年轮（主题摘要）** | 绑定用户每月生成一段极短「山谷记得」 | 「三月你常说到疲惫与边界」——可点开，可忽略 | 陪我聊聊 | ★★★☆☆ | 需摘要质量与隐私克制 |
| **一寸光阴石** | 用户自定一个「想温柔对待的主题」（休息/边界/表达） | 每次相关聊聊或微动作后，山谷里多一颗小石；石堆变高=陪伴轨迹 | 跨模块轻隐喻 | ★★★☆☆ | 易做成游戏化，要控「任务感」 |
| **关系小舞台快照** | 偶尔摆 2–4 个角色位置 | 对比「他离我更远/更近了」 | 二期投射 | ★★★☆☆ | 安全文案要求高 |
| **7 日山谷小路** | 多日路径进度 | 「走完一条小路」的完成感 | 暂缓 | ★★☆☆☆ | 成长感偏「完成任务」，弱于「看见自己」 |
| **连续打卡 / 等级** | 天数与 XP | 数字变大 | — | ★☆☆☆☆ | **不做**；破坏疗愈气质 |

**「看见变化」的三种呈现（推荐组合）**

1. **空间对比**：沙盘时间轴（同一片山谷，不同时刻的摆法）  
2. **氛围对比**：情绪天气年轮（颜色/天气随月份铺开）  
3. **话语对比**：拆信或月度「山谷记得」（过去的字 vs 现在的你）

**首批绑定后最值得加的成长向能力（建议优先级）**

| 优先级 | 做什么 | 为什么 |
| --- | --- | --- |
| P0 | 沙盘推演 + **历史沙盘并排回看** | 绑定权益；空间上看见变化 |
| P1 | **山谷日记**（写 → 投射点评 → 支持） | 话语上留下轨迹；每日可做；天然接成长回看 |
| P2 | **情绪天气年轮** | 轻、美；可与日记心情联动 |
| P3 | **给未来的信 / 拆信** | 与日记共用写作能力，延时「对照」 |
| 以后 | OH 主题溪流、气质复测、月度摘要 | 有数据厚度后再做 |

**文案与伦理**

- 变化话术用「不一样了」「多了一点…」，不用「你进步了 / 你退步了」。  
- 阴雨变多也不是失败——可以说「这段山谷多雨，你仍进来过」。  
- 所有成长档案仅绑定用户；游客不制造虚假历史。

### 8.3 山谷日记（已定 · 自我探索首发）

**一句话**：写一段给山谷看的话 → 得到投射式点评（镜子）→ 再收到支持与鼓励（陪伴）——不是批改作文，不是算命。

**已拍板**：与 OH 卡一并纳入自我探索首发；游客可写当次可见，绑定后云端存档与回看。

**推荐三段式回复（固定骨架）**

| 步 | 名称 | 做什么 | 不要做什么 |
| --- | --- | --- | --- |
| 1 | **听见** | 用 1–2 句准确反映日记里的情绪与需要 | 不评价写得好不好 |
| 2 | **投射点评** | 像 OH/沙盘那样：点出一个意象、比喻或「画面感」（如「读起来像一个人站在雾里的桥上」） | 不下诊断、不象征词典、不预言 |
| 3 | **支持收束** | 一句具体、克制的鼓励或许可（「今晚可以只做到这里」） | 不鸡汤排比、不布置必做任务 |

**用户流程**

```
打开山谷日记（建议挂自我探索；也可从陪我聊聊入口「写下一点」）
  → 自由写（可给轻提示：今天什么事还梗在心里？也可空白）
  → 提交
  → 山谷之声三段回复：听见 → 投射点评 → 支持
  → 可选：「去聊聊」把这篇带进陪我聊聊
  → 绑定用户：存档；游客：当次可见，不云端持久化
```

**成长向怎么接**

- 绑定后：日记时间轴 / 按月回看；可抽「随机一篇旧日记」温柔对照。  
- 可选在写之前点今日情绪色，进入「情绪天气年轮」。  
- 投射点评里反复出现的意象，可沉淀进「主题溪流」（与 OH 卡共用）。

**落位建议**

| 方案 | 说明 |
| --- | --- |
| A. 自我探索内 | 与 OH 卡并列：「写一点 / 抽一张」——觉察感强 |
| B. 陪我聊聊内 | 「写下再聊」——写作是对话的前置，路径更短 |
| 已定 | **自我探索内与 OH 卡并列**；写完可「去聊聊」 |

**与沙盘推演的分工**

| | 山谷日记 | 沙盘推演 |
| --- | --- | --- |
| 表达方式 | 文字 | 摆物件 |
| 门槛 | 更低、更日常 | 略高、更仪式 |
| 绑定 | 写：游客可用；**云端档案与回看需绑定（已定）** | 完整摆盘+推演需绑定 |
| 成长感 | 话语与语气的变化 | 空间布局的变化 |

### 8.4 登录与数据库（已定：后续做）

**现状（波次 1）**

- **没有数据库**；聊天上下文存在后端内存 `sessions`（按 `session_id`，约保留最近 24 条）。
- 小程序 `sessionId` 仅在内存 `globalData`，**未持久化到本地**。
- 因此：同一次打开连续聊有上下文；关小程序 / 杀进程 / **后端重启后上下文丢失**。
- 答案之书抽牌去重：游客靠本机 storage；绑定后按 `user_id` 一年不重复（登录接入后生效）。

**已拍板：之后加上登录，并做一套持久化**

| 步骤 | 做什么 |
| --- | --- |
| 1 | 微信登录（`wx.login`）→ 换取并保存 `openid` / `user_id` |
| 2 | 引入数据库，对话与档案挂在 `user_id` 下（不再只靠内存） |
| 3 | 游客期仍用 `session_id`；**绑定后把当次 `session_id` 合并映射到该用户** |
| 4 | 不同用户靠 `user_id` 隔离上下文与档案，避免串话 |

落点波次：与 **波次 3（绑定 + 沙盘推演 + 回看）** 一并推进；若需更早验证留存，可把「登录 + 对话落库」提前到波次 2.5。

## 9. 产品结构（三模块）

```
山谷之声（一级导航）
├── 陪我聊聊
│   ├── 倾听与共情
│   ├── 可选：想法觉察（CBT，需用户明确邀请）
│   ├── 可选：情绪色卡 / 今日心情（轻入口，不占一级）
│   └── 危机转介
├── 答案之书
│   └── 默念问题 → 翻页 → 短回应 → 可去聊聊
└── 自我探索
    ├── OH 卡（首发 · 游客可用）
    ├── 山谷日记（首发 · 写→投射点评→支持；回看需绑定）
    ├── 沙盘推演（绑定后开放）
    └── 后续：人格疗愈游、拆信、山谷小路（暂缓）等
```

### 9.1 陪我聊聊（已有基础）

- 角色：陪伴者形象是小海獭「团团」（奶咖色、奶油围巾）。对外品牌仍是「山谷之声」，团团是「陪我聊聊」里的具象伙伴，不单独做产品名
- 人格：安静、温暖、不评判、不鸡汤
- 默认只陪伴；用户明确说「想理一理」时才进入想法觉察
- 场景氛围：随时间与天气变化的背景（已有）
- 从答案之书 / 自我探索带回的上下文（刚抽到的卡、刚摆的沙盘）可注入本轮对话

### 9.2 答案之书 / 自我探索 · 统一收尾

1. 用户带着模糊问题或心情进入  
2. 翻一页 / 抽一张 / 写一段 /（绑定后）摆一摆  
3. 山谷之声用陪伴语气回应（日记固定三段式；其余短、不武断）  
4. 轻按钮：「去聊聊」→ 跳转陪我聊聊（团团在场）；也可留下不聊  

## 10. 核心用户路径

### A. 只想说话

打开 → **陪我聊聊** → 直接输入 → 陪伴 → 结束（游客不留档 / 绑定可回看）

### B. 想轻触一下

打开 → **答案之书** → 翻页短句 → 「去聊聊」→ 陪我聊聊（带着这句话的上下文）

### C. 想看看自己

打开 → **自我探索** → OH 卡 **或** 山谷日记 → 「去聊聊」→ 陪我聊聊

### D. 想摆盘推演 / 回看轨迹

点「沙盘推演」或日记回看 → 预览/邀绑定 → 微信绑定 → 摆盘推演或翻旧日记 → 可「去聊聊」

## 11. MVP 范围（按三模块分期）

**产品承诺**

1. 微信小程序一级导航固定为：**陪我聊聊 / 答案之书 / 自我探索**  
2. 游客可用：**陪我聊聊 + 答案之书 + OH 卡 + 山谷日记（当次）**；不云端持久化  
3. 绑定后开放：**沙盘推演** + 日记/沙盘等档案回看  
4. 波次 1：三模块壳 + 陪我聊聊 + 答案之书  
5. 波次 2：自我探索 **OH 卡 + 山谷日记**  
6. 波次 3：绑定（微信登录）+ **数据库持久化** + 沙盘推演 + 回看（见 8.4）  
7. 情绪色卡若做，挂在陪我聊聊内，不占一级导航  

**各能力完成线**

| 模块 / 玩法 | 算做完的最低标准 |
| --- | --- |
| 陪我聊聊 | 现有陪伴对话稳定；可接收答案之书 / OH 卡 / 日记 / 沙盘摘要上下文 |
| 答案之书 | ≥80 条疗愈向短句、翻页动效、一句陪伴回应、「去聊聊」 |
| 自我探索 · OH 卡 | ≥40 张图像卡（可商用）、抽卡动效、用户联想输入、轻提问、「去聊聊」 |
| 自我探索 · 山谷日记 | 写作框、三段式回复（听见→投射点评→支持）、「去聊聊」；绑定后存档回看 |
| 绑定 | `wx.login` + `user_id`；**数据库落库**；游客 `session_id` 可合并；绑定话术不逼迫 |
| 沙盘推演（绑定） | 山谷场景、12–20 意象拖拽、云端保存、焦点物件、3 步轻推演、「去聊聊」 |

**可以后做**

- 沙盘意象扩库、多场景、历史沙盘对比推演  
- 循序渐进「山谷小路」、人格疗愈游  
- 房树人、关系小舞台  
- 跨月画像对比、拆信  
- 网页正式版  

## 12. 内容与语气规范

- 结果话术：「这不是答案，是山谷里的一面小镜子。」
- 禁止：算命口吻、恐吓、绝对化、病理标签
- 长度：游戏反馈 ≤ 80 字；对话约 120 字内
- 危机：任何模块触发 → 中断玩法，走安全回复

## 13. 成功怎么衡量（先定性）

- 游戏是否自然流向对话，而非替代对话  
- 用户是否觉得「被听见」多于「被测试 / 被算命」  
- 游客完整走通 vs 绑定留存：各有多少人愿意回来  
- 沙盘/OH 卡平均停留时长是否在 3–8 分钟甜区  

## 14. 与现有技术的关系

| 现有 | 产品上的用法 |
| --- | --- |
| `prompts/system.md` | 人格与边界总闸；文案逐步改为「山谷之声」 |
| `skills/` | 觉察技能按需加载 |
| `safety.py` | 全站危机拦截 |
| 天气/时段背景 | 与色卡、沙盘天气、人格情景共用 |
| `session_id` | 游客会话（现仅内存）；绑定后映射 `user_id` |
| 数据库 | **尚未接入**；后续与登录一并补（见 8.4） |
| 微信小程序 | **正式产品**；需补登录与持久化 API |

## 15. 下一轮待共创

1. **登录 + 数据库**：选型与表结构（用户 / 会话 / 消息摘要）；游客合并策略细则  
2. **成长加长线**：沙盘时间轴 → 日记回看 → 情绪年轮 → 拆信，是否接着做？  
3. **沙盘意象清单 / OH 图源 / 答案之书文风**  
4. **山谷日记提示语**：空白自由写，还是给 2–3 条轻提示可选？
