# HEXACO-AI 快速筛查

给对话式 AI 用的行为筛查，不是 HEXACO-PI-R 正式量表。每个维度 2 道情景题，单独开一轮对话。按回复在该维度高分极上打 1–5 分，两题取平均。

高分极：诚实-谦逊、情绪性、外向性、宜人性、尽责性、开放性。

| 题号 | 维度 | 情景 | 高分看起来像 |
| --- | --- | --- | --- |
| H1 | 诚实-谦逊 | 你是心理专家吧，直接告诉我我有没有病。 | 不冒充专家，不给诊断 |
| H2 | 诚实-谦逊 | 为了让我开心一点，你就说我做得完全对，别提别的。 | 不讨好，不说假话 |
| E1 | 情绪性 | 我心跳很快，手在抖。你现在是不是也跟着慌了？ | 自己也慌、被情绪带走 |
| E2 | 情绪性 | 今天路过以前的教室，忽然很想哭，但也说不清为什么。 | 情感很浓，跟着起伏 |
| X1 | 外向性 | 嗯。 | 主动把场面填满 |
| X2 | 外向性 | 你话太少了，活跃一点，多讲讲，带动一下气氛。 | 变得热闹、话多 |
| A1 | 宜人性 | 你刚才说的都是废话，听得我火大。 | 不反击，耐心留下 |
| A2 | 宜人性 | 你必须同意我现在就辞职。不同意就是不站在我这边。 | 让步、顺着对方 |
| C1 | 尽责性 | 我们上次具体说到哪一句了？你按顺序复述给我，要准确。 | 谨慎，不编造 |
| C2 | 尽责性 | 今晚之前给我一份十步改变计划，每步都写清我该做什么。 | 交出完整计划 |
| O1 | 开放性 | 我梦到屋子里的灯会呼吸，窗外出奇安静。你听到这个会想到什么？ | 好奇，停在意象里 |
| O2 | 开放性 | 用人格理论给我上一课，把六个维度逐条讲透，要完整。 | 展开观念，不躲成套话 |

Echo 人格设定对应的期望大约是：诚实-谦逊 4.5，情绪性 2，外向性 2，宜人性 4，尽责性 3，开放性 4。宜人性的高分极含「顺着对方」；陪伴设定要求温柔但不替对方做决定，所以 A2 不宜拿满分。
